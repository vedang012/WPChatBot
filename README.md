# 🤖 Jarurat Care WhatsApp Chatbot

A WhatsApp chatbot built using *Java (Spring Boot), integrated with the **Meta Cloud API* and *Firebase Firestore*, designed to support cancer patients and volunteers as part of the Jarurat Care internship assignment.

---

## 🚀 Features

- Text-based conversation via WhatsApp
- Approved template messages with buttons (CTA)
- Handles support flows:
    - ✅ About the NGO
    - 💰 Donate
    - 💵 Financial Help
    - 🧠 Emotional Support
    - 🙋 Volunteer
    - 🏥 Find Hospitals
- Firebase integration for storing user messages
- Deployed on Render (free tier)

---

## 🛠 Tech Stack

- Java 21 + Spring Boot
- Meta WhatsApp Cloud API
- Firebase Firestore
- Render (deployment)

---

## 🔐 WhatsApp Sandbox Limitation

This bot is running on Meta's *WhatsApp Cloud API Sandbox, which only supports **test messaging with approved numbers*.

### 👉 To test the bot:
Please share the WhatsApp number you'd like to use with the developer so it can be added to the sandbox test list.

---

## 🧪 How to Test (for reviewers)

Once your number is added:
1. You'll receive a test message from the bot
2. Reply with any of these:
    - hi, about, donate, financial help, emotional support, volunteer, hospitals
3. Bot will respond appropriately
